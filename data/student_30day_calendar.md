## How Mike teaches each day
1. Hook (question / bold claim)
2. Definition on board
3. One fact students can repeat
4. Did you know
5. Takeaway
6. CTA: “Comment what you understood” OR “Comment the next topic you want” + “Follow for more”

## Move rules (no side-walk)
- Start: question face
- Explain: talk
- Definition on board: point
- Fact: talk / happy
- End: present → talk
- Sit only for “study tip” days (28–30)
