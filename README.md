# MEZI 2D Talking Clip Factory

Cartoon explainer pipeline inspired by **MEZI the Curious Explorer**.

```
text → Edge TTS → Rhubarb → 2D MEZI puppet (idle/walk/point/laugh) → mp4
```

**Truth:** procedural 2D puppet (yellow hoodie), not the full illustrated sheet — but it talks, walks, points, laughs in a simple room on free Actions.

## Run

Actions → **Render talking clip** → set `actions` e.g. `idle,point,walk,laugh` → download **mezi-clip**.
