# MEZI TikTok factory — sprite puppet

```
Wikipedia -> script (Qwen/template) -> TTS + Rhubarb
  -> sprite layers (body + mouth + point/laugh)
  -> vertical mp4
```

Sprites are built in CI by `scripts/write_mezi_assets.py` into `assets/mezi/`.

Push to `main` or run **Render talking clip**. Artifact: **mezi-tiktok**.
